# Third-party notices

Slate redistributes open-source components inside its runtime. Their full license texts travel
with the code they cover:

| Location | Covers |
| --- | --- |
| [shell/vendor/LICENSES/](shell/vendor/LICENSES/) | marked, highlight.js and its GitHub themes, DOMPurify, and the Material Symbols Outlined font |
| [shell/canvas/THIRD_PARTY_NOTICES.txt](shell/canvas/THIRD_PARTY_NOTICES.txt) | Every package bundled into the Canvas application, generated by `npm run build:canvas` |

[docs/third-party-notices.md](docs/third-party-notices.md) lists each component with its version
and license, the build-time tools that are not redistributed, icon and font attribution rules, and
the procedure for updating a component. `npm run test:third-party-notices` keeps all of these in
step with what actually ships.

This file covers third-party material only and does not grant a license to Slate itself.
