Slate documentation system

Slate

A portable, zero-configuration viewer that turns Markdown and HTML content into a beautiful, navigable documentation site.

TL;DR

This demo is a working content root. It renders HTML and Markdown pages through one pipeline, styles them with a token-driven design system, and adds navigation, search, a table of contents, theming, and deep links - with no build step.

Every example follows one made-up storyline: a small company carrying a dangerous Ring to the only fire that can unmake it. It is a fictional, affectionate homage written for this demo, not affiliated with any rights holder, and all of its numbers are invented. Hover or focus DEC-02 to preview a Council decision from another page without leaving this one.

How it works

You provide

  • Content pages (.html or .md)
  • A docs-manifest.json
  • Optional slate.config.json for branding

Slate provides

  • Design system + components
  • Navigation, search, TOC, deep links
  • Theming, sanitization, responsiveness

Try it

Open Revision in the header to collect change requests against one or several blocks. Continue to another page and add more comments to the same revision. Run the reader through Slate's loopback server to save JSON automatically into the parent project's fixed .slate/revisions/ directory, with no manual file saving. Static hosting remains read-only for revisions. Archived revisions remain available for reopening.

Tip

Toggle the theme (top right), press Ctrl/Cmd-K to search, and edit slate.config.json's brandColor to rebrand the whole site with no code change.
